# 🛒 Grocery App

A modern online grocery shopping application inspired by Blinkit, designed to provide a smooth and convenient grocery-shopping experience.

## 🌐 Live Demo

🔗 [https://groceryapp-orcin.vercel.app/](https://groceryapp-orcin.vercel.app/)

## ✨ Features

- 🛍️ Browse grocery products
- 🔍 Search for products
- 🗂️ Explore different product categories
- 🛒 Add products to cart
- ➕ Increase or decrease product quantities
- 🧾 Manage shopping cart items
- 📱 Responsive and user-friendly interface

## 📸 Overview

The application brings together essential grocery-shopping functionalities in a simple and intuitive interface, making it easier for users to explore products and manage their shopping carts.

## 📚 Learning Experience

This project was developed as a hands-on learning experience using an existing application as a reference. I explored the codebase, experimented with **REA (Reverse Engineer Anything)**, and used AI-assisted development to understand application structure, functionality, and implementation workflows.

It helped me learn how to explore unfamiliar codebases, understand how different components interact, and approach application development through experimentation.
